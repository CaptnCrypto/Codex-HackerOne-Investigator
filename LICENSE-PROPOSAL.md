# License decision: Apache License 2.0

The selected license is the **Apache License, Version 2.0**. The standard license
text is included as `LICENSE`.

Why it fits:

- permissive use, modification, and redistribution;
- an explicit patent license valuable for security tooling;
- preservation of copyright and license notices;
- compatibility with commercial and research use.

Before publication, the repository owner must confirm that every included contribution
is original, owned by the publisher, or otherwise redistributable under Apache-2.0.
The file audit found no embedded third-party notices or non-standard-library runtime
dependencies, but a filesystem review cannot independently prove authorship.

Alternatives:

- MIT: shorter and simpler, but without Apache-2.0's express patent grant.
- MPL-2.0: file-level copyleft if improvements to core files should remain public.

This is a project-maintenance proposal, not legal advice.
