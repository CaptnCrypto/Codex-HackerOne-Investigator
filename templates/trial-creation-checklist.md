# Manual owned-lab creation checklist

Create an account or trial only when the current program policy explicitly permits it.

- [ ] Review the current authenticated program policy and terms personally.
- [ ] Confirm account or trial limits and record prior usage privately.
- [ ] Follow required researcher-email and account-labeling conventions.
- [ ] Use no real customer identity, data, production credential, or production file.
- [ ] Do not enter payment data unless the program explicitly requires and authorizes it.
- [ ] Record a local, non-secret lab reference and creation timestamp.
- [ ] Record the exact assigned hostname without credentials or session material.
- [ ] Verify the hostname against the current authenticated scope; do not infer scope from a suffix.
- [ ] Add only the exact lowercase hostname to a private allowlist copy; never add a wildcard.
- [ ] Set target approval only after ownership and authorization are confirmed.
- [ ] Keep execution disabled through policy, target, and rate-control review.
- [ ] Create only clearly labeled synthetic users and data.
- [ ] Use distinct browser profiles for controlled roles.
